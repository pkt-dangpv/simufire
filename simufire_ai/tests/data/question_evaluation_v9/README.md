# Corpus 9 · observaciones previas ante aperturas repetidas

Los mismos 160 casos expuestos y 14 historiales sintéticos; todos son regresiones.
Seis expectativas de ámbito y presentación se modifican explícitamente a partir
de E08: respuesta del tramo previo común sin aclaración, cobertura interna
insuficiente y ninguna detección confirmada nueva. El archivo
`expectation_changes.json` conserva antes, después y motivo. No se cambia la
selección de hechos ni de conocimiento. Las demás expectativas siguen iguales.

Entradas físicas, umbrales y biblioteca histórica se conservan byte por byte.
La nueva explicación docente de backdraft se verifica aparte con la biblioteca
actual; no se añade retrospectivamente a los contextos históricos ni se presenta
como detector. El corpus se congela antes de ejecutar la evaluación. No hay un
reservado nuevo ni un benchmark independiente de Qwen.
