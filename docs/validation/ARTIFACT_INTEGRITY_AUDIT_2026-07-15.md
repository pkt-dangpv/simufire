# Validation Artifact Integrity Audit - 2026-07-15

## Scope

This audit followed repeated native Godot access-violation dialogs during
Codex-driven runs. It checks whether crashed or sandbox-blocked processes left
truncated, duplicated or incorrectly accepted validation outputs.

This is an artifact-integrity audit. It does not recalibrate physics or claim
that every same-stem CSV and JSON was generated by the same runner and run.

## Result

- Official CSV corpus: **29 files, 48,884 rows, 0 integrity failures**.
- Technical scratch packages: **84 complete, 0 partial, 0 malformed**.
- Duplicate `(time_s, room_id)` rows: **0**.
- Snapshots with missing or repeated rooms: **0**.
- Rows with invalid width, parse error, NaN or infinity: **0**.
- Files ending before their configured duration: **0**.
- Tracked changes left by failed Godot launches: **0**.

The 0.9/1.1, 4.9/5.1 and 9.9/10.1 second intervals are expected fixed-step
quantization around nominal 1, 5 and 10 second logging. Every affected file
has the expected snapshot count and the short/long intervals compensate.

## Crash Attribution

The native dialogs occurred when Godot was launched inside the Codex file
sandbox. Godot could not create `user://logs` under AppData and could terminate
before simulation startup. Runs launched outside that sandbox completed.

The stored run contract requires `summary.json`, `events.json`, `sim_log.txt`,
`sim_log.csv` and `run_manifest.json`, plus valid schema markers. All 84
packages exposing this contract are complete. A failed launch therefore did
not masquerade as a successful motor run.

## Separate Provenance Debt

There are 26 official CSVs with a same-stem report JSON and three legacy
diagnostic CSVs without a matching case (`ilv_open_window_repro`,
`p2h_diag_off`, `p2h_diag_on`). Same-stem artifacts have historically been
produced by two workflows:

- `scripts/run_scenario.py` / `tools/run_scenario_headless.gd` for technical
  CSV packages;
- `sim/validation/run_case.ps1` / CaseRunner for validation report JSON.

Their final values are not a reliable same-run checksum. The existing
freshness audit also reports four stale JSON reports and historical experiment
reports without case files. This is repository hygiene debt, not crash
contamination, and must not trigger bulk regeneration during Phase 3 shadow
work.

## Reproducible Check

```powershell
python scripts/simulation/audit_artifact_integrity.py
```

The read-only command exits non-zero for malformed CSVs, incomplete room
snapshots, duplicate rows, duration mismatches, partial technical packages or
invalid package schemas. CSV/JSON provenance remains informational rather than
asserting false same-run equivalence.

## Decision

The current validation artifacts are structurally sound. No report
regeneration is required before F3.0i. Codex must continue launching Godot
outside the file sandbox, and a native crash or non-zero exit must never be
accepted without the complete artifact contract and normal validation suites.
