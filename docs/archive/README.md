# Documentation Archive

Esta carpeta contiene material conservado por trazabilidad, pero que no forma parte de la entrada principal del producto.

- `root-artifacts/`: logs, salidas temporales, snapshots y resultados que estaban versionados en la raíz del repositorio.

Los artefactos aquí no deben ser consumidos por el runtime de Godot ni por los comandos oficiales. Si un archivo pasa a ser una entrada necesaria, muévelo a una carpeta de dominio clara (`scenarios/`, `sim/validation/`, `scripts/`, etc.) y documéntalo en `docs/INDEX.md`.
