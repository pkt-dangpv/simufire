# Root Artifacts Archive

Archivos que antes estaban en la raíz del repositorio y se conservaron para trazabilidad:

- logs de ejecuciones Godot o validación;
- salidas `tmp_*`;
- snapshots `last_*`;
- escenarios o JSON de trabajo sueltos.

Esta carpeta es histórica. No debe usarse como fuente oficial para ejecutar SimuFire.
