# Scripts

Esta carpeta contiene comandos oficiales de consola. La lista pública se mantiene en `docs/COMMANDS.md`.

Los scripts exploratorios no deben añadirse aquí sin una descripción clara, manejo de errores y rutas relativas a la raíz del repositorio.

Entradas actuales:

- `check_product.py`: checks de producto/editor.
- `run_scenario.py`: ejecución headless de escenarios.
- `generate_fire_graphs.py`: generación de gráficas.
- `generate_code_report.py`: informe de código.
- `download_fire_literature.ps1`: actualización de bibliografía local.
- `clean_workspace.ps1`: limpieza de artefactos locales ignorados.
